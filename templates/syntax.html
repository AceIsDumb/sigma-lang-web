Sigma Language Syntax

File Structure

Sigma files use the .sigma extension or include !>sigma as the first line.

Data Types

Type Description Example
integer Whole numbers 1, 42
float Decimal numbers 3.14, 2.71
boolean True or false values true, false
nonetype Represents null/none value none, nothing
string Text enclosed in double quotes "hello, world!"
Note: Strings can include variables by using ${variableName} syntax.
Example: print "the count is ${count}"

Variable Assignment

Variables are stored as a dictionary (globals.py > variables)

Assigning variables:

let <type> var <name> be <expression>
let <type> const <name> be <expression>

Reassigning variables:

change <name> to <value>

Example:

Sigma: 
let int var count be 5
let string const message be "hello, world!"
change count to 10
Python equivalent: 
count: int = 5
message: str = "hello, world!"
count = 10

Comments

Comments are surrounded by <-- and -->

<-- This is a comment -->

Conditionals

if (<statement>) then do
    expression
    expression
elif (<statement>) then do
    expression
else do
    expression
fi

Example:

Sigma: 
if (x is greater than 10) then do
    print line "x is large"
elif (x is equal to 10) then do
    print line "x is 10"
else do
    print line "x is small"
fi
Python equivalent: 
if x > 10:
    print("x is large")
elif x == 10:
    print("x is equal to 10")
else:
    print("x is small")

Loops

While Loop:

while (<condition>) do
    expression
elihw

Example:

Sigma: 
while (count is greater than 0) do
    print "count: ${count}"
    change count to (count minus 1)
elihw
Python equivalent: 
while count > 0:
    print(f"count {count}")
    count -= 1

Logical Operations

All logic should be between brackets

Operation Sigma Syntax Equivalent Operator
Greater than <statement> is greater than <statement> >
Less than <statement> is less than <statement> <
Greater than or equal to <statement> is greater than or equal to <statement> >=
Less than or equal to <statement> is less than or equal to <statement> <=
Equals <statement> equals <statement> ==
Not equals <statement> is not <statement> !=

Logical Operators:

  • And: and
  • Or: or
  • Not: not

Example:

Sigma: 
if ((x is greater than 5) and (y is less than 10)) then do
    print "x and y are in range"
fi
Python equivalent: 
if x > 5 and y < 10:
    print("x and y are in range")

Printing

Sigma: 
print "print without newline"
print line "print with newline"
Python equivalent: 
print("print without newline", end="")
print("print with newline")

Receiving Input

receive to variable

Example:

print "input username: "
receive to username
print "welcome, ${username}"
